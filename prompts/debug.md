Debug this problem: ${@:-(use the problem I just described)}

Work methodically:

1. Restate the observed symptom and expected behavior.
2. Reproduce it (or state exactly what you need to reproduce it).
3. Form hypotheses about the root cause, ranked by likelihood.
4. Investigate each hypothesis using the code, logs, and tests — cite evidence.
5. Identify the root cause (not just the symptom).
6. Propose the minimal fix, and note any related risks.

Do not apply the fix until I confirm, unless I already asked you to fix it.
